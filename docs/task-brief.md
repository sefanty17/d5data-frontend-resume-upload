# 02 · 前端：设计稿还原

| 项目 | 内容 |
| --- | --- |
| 岗位 | 前端工程师（实习） |
| 原题 | Implement this design using a front-end framework or HTML/CSS. Submit a Github Link. |
| 交付 | GitHub 仓库链接 |
| 设计稿 | Figma（链接见 `链接与附件.md`） |

> 设计稿已通过 Figma REST API 抓取：节点树、2x 渲染图、插画与图标素材都在 `设计稿/`，解析见 `设计稿/设计说明.md`。

## 要求

1. 打开 Figma 设计稿，按稿实现页面；
2. 技术栈任选——前端框架（React / Vue / Svelte…）或纯 HTML/CSS 均可；
3. 提交一个 **GitHub 链接**（不是压缩包）。

## 仓库里建议写清楚的（自检用，非题目硬性要求）

- 技术栈、启动命令（`npm i && npm run dev` 之类）；
- 设计稿对照：运行截图或实现说明；
- 响应式范围（设计稿宽度、断点处理）；
- 未能还原或主动简化的部分；
- 图片 / 图标 / 字体的来源与授权。

## 还原自检（建议）

- [ ] 布局、间距、字号、行高、颜色、圆角、阴影与稿一致
- [ ] 交互状态：hover / focus / active / disabled
- [ ] 小屏与大屏断点
- [ ] 语义化标签、键盘可达、基础 a11y
- [ ] 控制台无报错，构建可复现
- [ ] 页面 1:1 截图与设计稿并排对照

## 本目录文件

- `题目原文.md`
- `链接与附件.md`（Figma 链接）
- `设计稿/`：抓取结果（`设计说明.md`、`tokens.css`、`raw/`、`renders/`）
- `提交清单.md`
