# 设计稿（放这里）

Figma 链接见上级目录 `链接与附件.md`。

## 已有文件

- `figma-preview.webp`：从 Figma 公开封面自动抓取的缩略图（799×240），只能看整体布局与封面上的评分口径文字，**不能**用来量像素；
- 各 Frame 的 PNG / PDF 仍需要你导出。

## 怎么把设计稿给到本机

1. 打开 Figma 文件（需要登录，或对方已开共享权限）；
2. 选中要还原的 Frame（页面）；
3. 右侧面板 **Export** → 选 **PNG（2x）** 或 **PDF**；
4. 命名清楚，例如 `home-desktop.png`、`home-mobile.png`、`all-pages.pdf`；
5. 放进本目录。

## 为什么需要导出

本机没有浏览器登录态，Figma 链接只能拿到页面外壳，读不到画布像素。导出图片 / PDF 后可以直接分析尺寸、间距、颜色、层级与组件拆分。

## 如果导出不方便

- 直接截图（PNG）也可以，尽量 2x、含完整 Frame；
- 能在 Figma **Inspect** 面板复制到的色值、字号、间距，记到 `说明.md` 里更好；
- **不要**提供账号密码。

## 收到后我会做什么

- 量出栅格、间距、字号、颜色，整理成 tokens；
- 标出可复用组件与状态（hover / active / disabled）；
- 给出断点与响应式建议；
- 列出还原风险点（字体、图标、图片资源）。
